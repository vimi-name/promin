# Contributing

1. Keep one normative fact under one canonical owner.
2. Preserve the product doctrine: humans define meaning; agents clarify and implement.
3. Do not add a persistent entity, registry, gate, or document without positive stressed NetValue.
4. Use portable relative paths and preserve Windows, macOS, and Linux behavior.
5. Add focused tests for every changed contract and run only the invalidated test lanes.
6. Declare the SPDX license and provenance of dependencies, presets, skills, and copied content.
7. Never commit caches, projections, host bindings, secrets, or personal data.
8. Generated reports are projections, not authority.
9. Heavy tests may be marked `alpha_deferred`, but never reported as passed when not executed.
