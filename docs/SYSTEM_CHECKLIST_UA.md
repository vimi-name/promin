# Системний checklist promin alpha

Запуск:

```bash
promin doctor --checklist
```

Checklist є bounded статично-операційною перевіркою. Він не запускає physical
100k, A/B або saturation кампанії й не дає release/pass credit.

## Поверхні

1. canonical identity і version owner;
2. рівно шість Core artifacts;
3. canonical init і resolved plan;
4. no-question-first і zero hidden scan;
5. project mode та heterogeneous workspace units;
6. dynamic profile composition;
7. Task/Grant/WorkCard orchestration;
8. host-neutral canonical paths і doctor repair;
9. hash-bound documentation;
10. bounded context projection;
11. Codex/Claude/Cursor pickup;
12. managed і existing host skills;
13. portable Git footprint;
14. model routing і bounded WorkCard;
15. token/resource budgets;
16. open-license і third-party notice surface;
17. heartbeat/self-audit;
18. explicit alpha-deferred heavy tests.

Кожна перевірка повертає `pass`, `warn`, `fail` або `deferred`, evidence і одну
конкретну remediation. Generated checklist не є source of truth.
